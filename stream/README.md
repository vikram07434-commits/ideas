# Stream

> AI-powered movie making website

## Vision

A web application that lets users create movies/short films using AI — from script generation to scene creation, voice acting, and final video assembly.

## Core Concepts

- **Script Generation** — AI writes screenplays from prompts/ideas
- **Scene Composition** — AI generates visual scenes (images/video clips)
- **Voice & Audio** — AI voice acting, music, sound effects
- **Video Assembly** — Stitch everything into a watchable movie
- **Collaboration** — Users can direct, edit, and iterate

## Tech Stack (TBD)

- Frontend: Next.js / React
- Backend: Node.js or Python
- AI APIs: OpenAI (GPT for scripts), image/video generation models, TTS
- Video: FFmpeg for assembly
- Hosting: Vercel / AWS
