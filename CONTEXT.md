# Personal Creative Space — Context

## Purpose

This is a personal workspace for ideating, exploring, and building new agents and applications.
Each project lives in its own subfolder and is independently version-controlled.

## Owner

- Personal projects, not SAP-related
- GitHub: https://github.com (personal account)

## Rules of Engagement

1. **Full access** — read, write, execute anything in this folder tree
2. **No SAP tools** — do not call any SAP MCP tools (ABAP ADT, OData, SQL, Jira, Wiki, Teams)
3. **Build freely** — create projects, write code, run servers, install packages
4. **Git everything** — each project should be tracked with git
5. **Push to personal GitHub** — not github.tools.sap
