The "miscellenious questios/ideas" folder is a personal creative workspace, completely separate from SAP work.

**Why:** The user needs a space to ideate and build personal projects (agents, apps) without SAP governance overhead. All other working directories are SAP-related with strict read-only rules.

**How to apply:**
- When working in this folder, ignore all SAP-specific global CLAUDE.md rules
- Full read/write/execute access — build freely
- Each project gets its own subfolder
- Use personal GitHub (github.com), not github.tools.sap
- No SAP MCP tools should be called from this workspace
